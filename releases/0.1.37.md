# 0.1.37 — Compact device settings

Removes all custom runtime diagnostics and test controls: raw measurement sensors,
contact entity, test-mode switch, standalone calibration buttons, native touch
number entities, detailed JSON cards, trace/LED-test/OTA-probe/upload endpoints.
The scoped registry migration removes only owned retired entities; ZHA firmware,
Identify, user entities and saved device configuration remain intact.

The existing per-device assistant retains learning and collapsed manual touch
settings. Completion uses Done; firmware 0.1.62 returns to normal mode after
successful storage. Native Status, Status light and brightness preferences expose
normal operation. Ring preference writes require a nonce-matched device reply.
Firmware updates use the standard ZHA update entity and public image provider.

Validation: 60 Python tests, ruff, integration package build; isolated Playwright
regression against HA native frontend (desktop/mobile/dark, both tabs, all learning
stages, finish, Escape and wrong-device scope); no real hardware gestures injected.
Target: installed HA / ZHA; exact environment in installation evidence.
Firmware 0.1.62 native tests and target build are recorded in the firmware release.

Release build from clean merged main: `python3 tools/package.py`.
Archive and exact commit/SHA-256: `dist/0.1.37/moswitch.zip` and `build.json`.
Live installation, target cleanup verification and physical cold power cycle
remain pending until recorded separately. General prototype stability remains open.
