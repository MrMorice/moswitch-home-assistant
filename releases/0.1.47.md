# 0.1.47 — withdraw autonomous OTA candidate

Withdraws firmware0.1.68-rc1 from the catalog. The active0.1.65 autonomous
candidate repeatedly resets its error counter during OTA and cannot reliably
complete the transfer. Physical target acceptance has not passed.

SDK bootloader calls temporarily change GPIO security attribution; autonomous
GPIO DMA must pause across those calls. A corrected local firmware candidate
adds explicit storage access guards. The exact reset fault is not yet captured;
the security interaction is a concrete compatibility gap, not a proven reset
trace. No automatic successor is offered to the affected prototype. USB/SWD
recovery and target validation are required before renewed OTA qualification.

No integration behavior or frontend changes. Validation:76 pytest tests,
Ruff, clean-main integration package. Build:python3 tools/package.py;
