# 0.1.40 — Discover firmware catalogs without HA restart

The normal MoSwitch ZHA provider caches its public catalog for five minutes
instead of zigpy's24-hour default. Device image queries can discover subsequent
verified releases without a Home Assistant restart. Provider registration also
works before room/light assignment and while the switch is being learned.
Firmware transport, image validation, manufacturer/model/version restrictions,
update consent and the compact device UI remain unchanged.

Validation:64 pytest tests, Ruff and package build. Real zigpy provider tests
exercise cache reuse and expiration without networking/restart; registration
is independent of room setup and idempotent. HA2026.10.4/ZHA; target PCBv4/XIAO.

Clean-main release: `python3 tools/package.py`; artifacts and source/checksum
metadata in `dist/0.1.40/`. Live installation follows the active firmware transfer.
