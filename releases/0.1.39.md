# 0.1.39 — Paired RC touch-profile support

Accepts the new profile-2 discriminator in the existing 76-byte protocol-10
status frame. Profile 1 and all legacy frames remain supported; other profile
identifiers are rejected. The paired measurement requires a new calibration;
its firmware uses a separate calibration bank and preserves the prior bank.
No diagnosis/test controls or endpoints are reintroduced.

Validation: 62 pytest tests, Ruff and integration archive build. Firmware 0.1.63
is offered only to 0.1.62 as an explicitly experimental target-board candidate.
Paired ACMP acquisition needs physical verification before a stable firmware
release or merge. HA version: 2026.10.4; target PCB v4 / XIAO MG24.

Build after clean-main merge: `python3 tools/package.py`.
Archive/commit/hash: `dist/0.1.39/moswitch.zip`, `build.json`.
